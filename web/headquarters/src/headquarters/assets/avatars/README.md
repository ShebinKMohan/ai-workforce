# Workforce portrait collection

Sixteen original illustrated headshots created for AI Workforce, including masculine and feminine presentations, varied skin tones, hairstyles and glasses. Rendered from the original local Workforce face artwork and bundled as SVG files. No third-party artwork, remote images, account, or runtime image generation is required. These portraits use the same project license as the source. Stable portrait IDs are persisted; filenames are an internal implementation detail.
